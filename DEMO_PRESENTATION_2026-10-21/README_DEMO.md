# เดโมสำหรับพรีบน PC เครื่องนี้

ตรวจระบบวันที่ 21 ตุลาคม 2569 โดยรันภาพจริงใหม่ 3 ภาพผ่าน HTTP API เดียวกับหน้าเดโม

## เปิดใช้งาน

1. ดับเบิลคลิก **OPEN_DEMO.cmd** ในโฟลเดอร์นี้ จะเปิด MQTT, Home Assistant และหน้าเดโมให้ หลังขึ้น READY
2. หน้าเดโม: http://127.0.0.1:8090/demo
3. เปิดก่อนพรีประมาณ 5 นาที เสียบไฟและรักษาเครื่องให้ตื่นระหว่างพรี อย่าปิด WSL ระหว่างใช้งาน
4. ถ้าเปิดหน้าเดิมค้างไว้ ให้กด Ctrl+F5 เพื่อรับหน้าที่ปรับล่าสุด

ไฟล์เปิดเดโมอาศัยโค้ดในโฟลเดอร์ Seminar และโมเดล/สภาพแวดล้อมใน C:\Users\NATCHAPOL\SeminarLab จึงต้องเก็บโฟลเดอร์นี้ไว้ตำแหน่งเดิม การคัดลอกเฉพาะโฟลเดอร์นี้ไปอีกเครื่องไม่เพียงพอ

## ลำดับสาธิตประมาณ 2–3 นาที

1. เลือกภาพ เช่น **R74946CAAC57E** (7-Eleven) ระบบตั้งทิศหมุนทวนเข็มให้จากข้อมูลเดิม การเลือกทิศยังเป็นหน้าที่ผู้ใช้ ไม่ใช่โมเดลหมุนอัตโนมัติ
2. กด **อ่านภาพด้วยระบบ** รอประมวลผล ไม่กดซ้ำ
3. ชี้กรอบสีเขียวจาก YOLO และเปิด **ผลจากเครื่องมือก่อนผู้ใช้แก้ไข** เพื่อดูข้อความ OCR กับ JSON จริง
4. เปรียบเทียบกับภาพและแก้ฟิลด์ในตารางก่อนส่ง ใส่ชื่อผู้ตรวจของผู้ที่ตรวจจริง หากอ่านไม่ออกให้บอกข้อจำกัดและอย่าอ้างว่าได้ตรวจครบ
5. กด **ยืนยันและส่งข้อมูล** แล้วกด **ตรวจสถานะปลายทาง** เมื่อ Home Assistant รับแล้ว จะระบุว่า “ได้รับรายการที่เลือกแล้ว” พร้อม event ID ตรงกันทั้งสองเซนเซอร์
6. อธิบายว่าข้อมูลนี้เป็นการซื้อเข้า ยังไม่ใช่ปริมาณของคงเหลือหรืออัตราการใช้

พูดประกอบได้ว่า: “วันนี้สาธิตการเชื่อมต่อกระบวนการบน PC ผล OCR และเนื้อหา JSON ยังมีข้อผิดพลาด จึงมีจุดให้ผู้ใช้ตรวจแก้ก่อนส่ง และเรายังไม่อ้างคะแนนความถูกต้องระดับฟิลด์จนกว่าจะมีเฉลยครบ”

- ค่าที่โมเดลส่งในรอบตรวจยังเป็น 92140.0 / 99300 / 0 ตามลำดับ เป็นค่าผลโมเดลที่มีข้อผิดพลาด ไม่ใช่ยอดซื้อที่รับรองว่าถูกต้อง การตรวจ HA วัดว่ารับข้อมูลตรงกับที่ส่ง

## ขอบเขตที่ตรวจแล้วและยังต้องลองก่อนขึ้นพรี

ตรวจแล้ว: เปิดบริการด้วยตัวเปิดเดโม, API อ่านภาพจริงทั้งสามขั้น, การยืนยัน/ส่งซ้ำ, MQTT, ค่าและ event ใน Home Assistant, ภาพกรอบตรวจจับ, UTF-8, JavaScript syntax และการอ้างถึงช่องในหน้าเว็บ

ภายหลังผู้ใช้ขอทดสอบด้วย Robot Framework ได้ตรวจการคลิกใน Chrome จริงแบบ headless แล้ว 5 กรณีผ่านหลังแก้ตัวทดสอบ รวมการล็อกอินและอ่าน event บนหน้าจอ HA ดู `ROBOT_TEST_README.md` กับ `robot_results/report.html` ผู้พรีควรซ้อมลำดับสาธิตบนเบราว์เซอร์และความละเอียดจอที่จะใช้จริง ข้อมูลฟิลด์ JSON ที่ถูกต้องและภาพต่างฉากใหม่ยังเป็นงานค้างเดิม

หลักฐาน: `presentation_pc_check_2026-10-21.json` ในโฟลเดอร์นี้ รายละเอียดผลโมเดลเก็บใน `C:\Users\NATCHAPOL\SeminarLab\preboard\runs\<pipeline_run_id>\pipeline.json` ตามรหัสในหลักฐาน

ไม่เปลี่ยนผลวิจัยหรือเนื้อหา Ass5/Ass6 จากการตรวจความพร้อมครั้งนี้
