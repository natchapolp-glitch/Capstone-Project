## ความหมายของข้อมูลใน HA หลังทดสอบ

ร้าน `ROBOT FRAMEWORK TRANSPORT TEST - NOT HUMAN TRUTH` และสินค้า `AUTOMATED UI TEST ITEM` เป็นค่าทดสอบการแก้ฟอร์มและส่งข้อมูล ตัวเลข 45 กับจำนวน 1 ใช้ตรวจการคงค่าและการส่งเท่านั้น ไม่ใช่ผลความถูกต้องของโมเดลหรือเฉลย JSON ที่มนุษย์รับรอง

ผู้ตรวจของรายการเป็น `robot_framework_automated_test_not_human_ground_truth` การทดสอบไม่เปลี่ยนข้อความอ้างอิงที่ผู้ใช้ตรวจไว้ในชุดข้อมูล

เมื่อซ้อมพรี ให้ประมวลผลและตรวจแก้ภาพของคุณ แล้วส่งรายการนั้น ค่าใน HA จะเปลี่ยนเป็นรายการล่าสุดที่คุณยืนยัน

## รันซ้ำ

เปิด PowerShell แล้วเรียก `Run-Robot-Tests.ps1` ในโฟลเดอร์นี้ จะเปิดบริการที่จำเป็นและเก็บผลแต่ละรอบใน `robot_results/run-<วันเวลา>` การรันทดสอบจะสร้างรายการทดสอบใหม่และอัปเดตค่าล่าสุดใน HA

ใช้สภาพแวดล้อมแยกที่ `C:\Users\NATCHAPOL\SeminarLab\.venv-robot` โค้ดต้นฉบับอยู่ที่ `tests/robot/demo_presentation.robot` กับ `tests/robot/DemoEvidence.py` ใน Seminar มีสำเนาสำหรับอ่านใน `robot_test_sources` และรายการเวอร์ชันใน `requirements.txt`

หากต้องติดตั้งสภาพแวดล้อมใหม่ ให้สร้าง Python venv สำหรับทดสอบ แล้วใช้ `python -m pip install -r tests/robot/requirements.txt` Selenium Manager ใช้จัดหา driver ให้ Chrome การเตรียม driver ครั้งแรกอาจต้องใช้อินเทอร์เน็ต

อ้างอิงวิธีใช้เครื่องมือ: [Robot Framework SeleniumLibrary](https://docs.robotframework.org/docs/different_libraries/selenium) และ [Selenium Manager](https://www.selenium.dev/documentation/selenium_manager/)
