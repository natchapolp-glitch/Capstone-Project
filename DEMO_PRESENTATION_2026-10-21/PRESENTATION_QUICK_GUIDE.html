  • รายงาน Word ฉบับจัดรูปแบบล่าสุด

ก่อนพรี 10 นาที: เสียบไฟ → เปิด OPEN_DEMO.cmd จาก File Explorer ในโฟลเดอร์นี้ → รอ READY → ล็อกอิน HA → ลองสลับหน้าจอและซูมให้เห็นชัด

แท็บ A: เดโม · แท็บ B: Home Assistant · แท็บ C: ผลรันที่บันทึกไว้

ลิงก์เดโมใช้ได้เมื่อบริการบน PC นี้ทำงาน ไฟล์ CMD ต้องเปิดจากโฟลเดอร์โดยตรง ข้อมูลล่าสุดใน HA อาจยังเป็นข้อมูล Robot ให้ตรวจแก้และส่งรายการของรอบสาธิตจริงก่อนใช้อ้างผล

สไลด์ประเด็นที่ต้องให้ผู้ฟังเข้าใจเวลาซ้อม

5–8ฐานวรรณกรรมเดิม → สิ่งที่นำมาออกแบบ → ช่องว่างที่เราศึกษา3 นาที

14–19ผลตรวจจับ / OCR / JSON → เดโมจริง → เวลาและทรัพยากรตามเงื่อนไขทดลอง7 นาที รวมเดโม
20–21สิ่งที่ยังค้าง → แผนต่อไป → สรุปและขอบคุณ / Q&A2 นาที
“โครงงานนี้ศึกษาระบบกลางสำหรับข้อมูลในบ้าน โดยเริ่มทดลองจากภาพใบซื้อสินค้า วันนี้จะแสดงหลักฐานบน PC ตั้งแต่ภาพไปจนถึงข้อมูลที่ผู้ใช้ตรวจและส่งเข้า Home Assistant ครับ”

ประโยคเชื่อมเข้าเดโม: “เมื่อเห็นผลแต่ละขั้นแล้ว ต่อไปผมจะแสดงว่าข้อมูลเดินผ่านระบบจริงอย่างไร และจุดไหนที่ผู้ใช้ต้องตรวจแก้ครับ”

3. เดโม: ภาพ → กรอบ → OCR → JSON → ตรวจแก้ → HA

  1. ที่สไลด์ 18 สลับไปแท็บ A เลือกภาพ R74946CAAC57E ตรวจทิศภาพ กด อ่านภาพด้วยระบบ ครั้งเดียว
  2. ชี้กรอบสีเขียว เปิด ผลจากเครื่องมือก่อนผู้ใช้แก้ไข ให้เห็น OCR และ JSON จริง
  3. เทียบภาพแล้วแก้ร้าน วันที่ ยอดรวม และแถวสินค้า ใส่ชื่อผู้ตรวจจริง อย่าส่งค่าผิดจากโมเดลโดยอ้างว่าตรวจแล้ว
  4. กด ยืนยันและส่งข้อมูล → ตรวจสถานะปลายทาง รอข้อความ ได้รับรายการที่เลือกแล้ว
  5. สลับแท็บ B กรอง sensor.seminar_latest_purchase_total ดู State และ Attributes เทียบ event_id กับแท็บ A แล้วตรวจ sensor.seminar_latest_item_count ของ event เดียวกัน
  6. กลับสไลด์ 19 อธิบายผลวัดเวลาเดิม แยกจากเวลาคลิกสดและเวลาที่คนตรวจแก้
“JSON ที่ผ่านรูปแบบยังมีเนื้อหาผิดได้ จึงต้องให้ผู้ใช้ตรวจแก้ก่อนส่ง การที่ Home Assistant รับข้อมูลตรงกันพิสูจน์การเชื่อมต่อ ส่วนความแม่นยำของโมเดลต้องวัดแยกครับ”

ถ้ารอนานกว่า 60 วินาทีหรือแก้ข้อมูลไม่ทัน: เปิดแท็บ C แล้วพูดว่า “ขอใช้ผลรันที่บันทึกไว้บนเครื่องนี้เพื่ออธิบายแต่ละขั้นครับ” ถ้า HA แสดง event อื่น อย่าอ้างว่ารับรอบนี้แล้ว

5. คำตอบสั้นสำหรับคำถามที่น่าจะเจอ

ทำ e-Senses หรือ e-Eye? e-Senses คือกรอบระบบรวม ส่วนหลักฐานทดลองระยะนี้ใช้ e-Eye ผ่านภาพใบซื้อสินค้า ยังไม่ได้ทดลอง e-Nose และ e-Skin

OCR ผิดมากแล้วมีประโยชน์อย่างไร? ผลนี้แสดงข้อจำกัดของเครื่องมือบนชุดข้อมูลจริงและช่วยกำหนดจุดที่ต้องปรับปรุง ตอนนี้พิสูจน์การเชื่อมกระบวนการพร้อมจุดตรวจแก้ได้ แต่ยังต้องพัฒนาความแม่นยำก่อนใช้จริง

JSON ส่งไปไหน? ไป MQTT broker ใน PC พอร์ต 18884 ที่ topic seminar/preboard/purchases/latest แล้ว Home Assistant รับและแสดงข้อมูล ชื่อ topic เป็นช่องข้อความ ไม่ใช่โฟลเดอร์

คำนวณของเหลือในบ้านได้แล้วหรือยัง? ตอนนี้มีข้อมูลซื้อเข้า การหาของคงเหลือและอัตราการใช้ยังต้องมีข้อมูลเพิ่มเติม

มีอะไรค้าง? ตรวจกรอบและกลุ่มธุรกรรมซ้ำให้ครบ ทำเฉลย JSON เพื่อวัดความถูกต้องเนื้อหา เก็บภาพต่างฉากใหม่ และวัด NPU / พลังงานบน RK3588 เมื่อมีอุปกรณ์

“สรุปคือเรามีฐานวรรณกรรม ชุดข้อมูล และหลักฐานทดลองจริงบน PC พร้อมต้นแบบถึง Home Assistant แล้ว ส่วนความถูกต้องเชิงเนื้อหา การทดสอบต่างฉาก และผลบนบอร์ดเป็นงานที่จะทำต่อครับ ขอบคุณครับ”

จัดทำ 21 ตุลาคม 2569 จากบทพูดและหลักฐานในโฟลเดอร์นี้ เป็นโพยซ้อม ไม่ได้เพิ่มผลทดลองใหม่ • ก่อนขึ้นพรีให้ซ้อมเต็มชุดหนึ่งรอบและตรวจบริการจริงอีกครั้ง
