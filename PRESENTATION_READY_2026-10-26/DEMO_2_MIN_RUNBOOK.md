# คู่มือพาเดโมในเวลา 2 นาที

หากยังไม่เคยใช้ ให้เริ่มจาก [คู่มือกดตามทีละขั้นพร้อมภาพ](CLICK_BY_CLICK_GUIDE.html) หรือ [ฉบับข้อความ](CLICK_BY_CLICK_GUIDE.md) ก่อน แล้วใช้ลำดับเวลาในหน้านี้ซ้อมช่วงพรี

ใช้ที่สไลด์ 18 ผู้สาธิตคือณัชพล ผู้คุมเวลาคือธนบดี เวลาทั้งชุดเป้าหมาย 9 นาที เผื่อ 1 นาที

## เลือกวิธีก่อนวันพรี

**แนะนำคลิปไม่เกิน 2 นาทีที่เจ้าของงานอัดและตรวจแล้ว** เพราะการอ่านภาพ การตรวจรายการ และการเปิด Home Assistant อาจกินเวลาจริงไม่แน่นอน คลิปต้องแสดงผลจากระบบจริงและระบุช่วงที่ตัดออก

หากยังไม่มีคลิป ให้ใช้ผลที่บันทึกไว้ตามขั้นตอนสำรองด้านล่าง และพูดว่าเป็นผลย้อนหลัง ห้ามบอกว่าเป็นการอ่านภาพใหม่ ไม่ต้องรอให้รันสดสำเร็จกลางการนำเสนอ

## เตรียมก่อนอัดหรือก่อนขึ้นพรี

1. เสียบไฟ ป้องกันเครื่องพัก ปิดข้อมูลส่วนตัว/การแจ้งเตือนที่อาจเข้าจอ
2. เปิด `../DEMO_PRESENTATION_2026-10-21/OPEN_DEMO.cmd` และตรวจข้อความจากตัวเปิด การขึ้น SERVICES READY หมายถึงบริการพร้อม ยังต้องลองภาพจริงก่อนใช้งาน
3. เปิดแท็บ A `http://127.0.0.1:8090/demo` และแท็บ B `http://127.0.0.1:8123/config/tools/state` ล็อกอินก่อนเริ่มบันทึก ไม่บันทึกรหัสผ่าน
4. เลือกภาพ `R74946CAAC57E` ตรวจทิศหมุนทวนเข็ม 90° ให้ชื่อร้าน/รายการอ่านได้จากภาพจริง เปิดภาพต้นฉบับหากต้องขยาย
5. ทดลองอ่านภาพหนึ่งครั้งก่อนอัด ตรวจว่ามีกรอบ ภาพโหลดครบ OCR และ JSON ไม่แสดงคำเตือนว่าโมเดลล้มเหลว แค่ pending_review ยังไม่รับรองว่า LLM สำเร็จ
6. **หลังรัน Robot ค่าใน HA เป็นข้อมูลทดสอบสังเคราะห์** เช่น `AUTOMATED UI TEST ITEM` ห้ามนำไปบอกว่าคนตรวจแล้ว หากต้องการคลิปตรวจจริง ให้เจ้าของงานตรวจแต่ละช่องกับภาพและลงชื่อจริงของตน
7. เปิดสไลด์แบบ Slide Show ลองสลับไปวิดีโอ/เบราว์เซอร์แล้วกลับหน้าถัดไปก่อนเริ่มจับเวลา

## ลำดับคลิปและบทพากย์ 120 วินาที

| เวลาในคลิป | ภาพ/การคลิก | บทพากย์ใจความ |
|---|---|---|
| 0:00–0:15 | แท็บ A เลือกภาพและทิศ กดอ่านภาพ | “ใช้ภาพจากชุดพัฒนาบน PC โดยเลือกทิศภาพก่อนประมวลผลครับ” |
| 0:15–0:30 | แสดงกรอบสีเขียว | “YOLO หาตำแหน่งเอกสาร กรอบนี้มาจากรอบที่เลือกครับ” |
| 0:30–0:50 | เปิดผลจากเครื่องมือก่อนผู้ใช้แก้ไข เลื่อนดู OCR และ JSON | “OCR อ่านข้อความแล้วส่งให้โมเดลภาษาสร้าง JSON ผลดิบยังมีข้อผิดพลาดและเก็บไว้ตรวจย้อนหลังครับ” |
| 0:50–1:20 | กลับฟอร์ม แสดงการตรวจเทียบภาพและแก้ช่องที่ผิด ลบแถวที่ไม่ใช่สินค้า | “ผู้ใช้ตรวจร้าน วันที่ สินค้า และยอดรวมก่อนส่ง ช่องที่ไม่มีข้อมูลในภาพเว้นว่างได้ แต่ข้อความที่อ่านไม่ออกต้องระบุข้อจำกัดครับ” |
| 1:20–1:35 | ใส่ชื่อผู้ตรวจ กดยืนยันและส่ง | “ข้อมูลหลังตรวจจึงถูกส่งผ่าน MQTT ไป Home Assistant ครับ” |
| 1:35–1:55 | ตรวจสถานะปลายทาง สลับแท็บ B กรอง `sensor.seminar_` | “เทียบยอดรวม จำนวนรายการ และ event_id เดียวกัน เพื่อยืนยันว่าปลายทางรับรอบนี้ครับ” |
| 1:55–2:00 | ปิดท้ายก่อนกลับสไลด์ 19 | “นี่แสดงการเชื่อมระบบ ส่วนความถูกต้องของโมเดลต้องประเมินแยกครับ” |

เวลานี้เป็นแผนตัดต่อ ไม่ใช่เวลา inference ที่วัดได้ ใช้ข้อความ “ตัดช่วงรอประมวลผล” เมื่อข้ามช่วงรอ และ “ย่อช่วงตรวจแก้โดยผู้ใช้” เมื่อย่นการตรวจ ห้ามเร่งคลิปให้เหมือนระบบทำงานจริงเร็วเท่านั้น

ชื่อคลิปที่ตกลงใช้: `DEMO_2_MIN.mp4` วางข้างคู่มือนี้เมื่ออัดเสร็จ ปัจจุบันคู่มือนี้ไม่ได้ยืนยันว่ามีคลิปแล้ว ตรวจภาพ เสียง ระยะเวลา และเปิดเล่นแบบออฟไลน์ครบหนึ่งรอบก่อนใช้ ไม่ต้องฝังใน PPTX หากการสลับหน้าต่างซ้อมแล้วคล่อง

## ตรวจข้อมูลอย่างไร

- ร้าน: อ่านหัวใบซื้อสินค้า ไม่ใช้ชื่อที่โมเดลเดา
- วันที่: ตรวจวัน เดือน ปีจากภาพก่อนแปลง พ.ศ. เป็น ค.ศ. ไม่ใช้วันที่ทดสอบ Robot เป็นวันที่ซื้อ
- ยอด: แยกยอดสุทธิ เงินรับ และเงินทอน
- รายการ: ลบหัวใบเสร็จ เลขเครื่อง ภาษี และข้อความท้ายใบที่ถูกอ่านเป็นสินค้า เพิ่มเฉพาะที่เห็นชัด
- ชื่อผู้ตรวจ: คนที่ตรวจจริงเท่านั้น ค่าจาก automation ต้องระบุว่าเป็นการทดสอบ
- ปลายทาง: ต้องเทียบ event_id พร้อมทั้งสองค่า การเห็นยอด 45 อย่างเดียวไม่พอ เพราะอาจค้างจากรอบก่อน

## เส้นทางสำรอง 2 นาที: ผลที่บันทึกไว้

ก่อนพรี เลือกรายการที่ตรวจไว้แล้วและคัดลอก URL `http://127.0.0.1:8090/demo?receipt=<receipt_id>` เก็บไว้ เปิดค้างก่อนขึ้นเวที หากใช้รายการ Robot ต้องเปิดเผยว่าเป็นข้อมูลทดสอบการส่ง

1. 0:00–0:15: “ขอแสดงผลที่ระบบบันทึกไว้จากรอบก่อน เพื่อให้เห็นขั้นตอนภายในเวลาครับ”
2. 0:15–0:45: ชี้ภาพและกรอบ เปิด OCR/JSON ดิบ พร้อม run ID
3. 0:45–1:10: ชี้ฟอร์มอธิบายช่องที่ตรวจแก้และการเก็บผลดิบ ไม่กรอกแทนคนและไม่กดยืนยันใหม่หากยังไม่ได้ตรวจ
4. 1:10–1:45: กดตรวจสถานะปลายทาง ถ้า event_id ตรง แสดงค่าและสลับไป HA ถ้าไม่ตรง บอกว่าหน้า HA เป็นรายการล่าสุดอื่น ใช้หลักฐานรอบเดิมประกอบแทน
5. 1:45–2:00: ย้ำว่าเป็นผลย้อนหลังและการส่งสำเร็จไม่ใช่คะแนนความถูกต้อง จากนั้นกลับหน้า 19

ถ้าเบราว์เซอร์หรือคลิปเปิดไม่ได้ ให้ใช้ตารางและภาพในสไลด์ 16–19 อธิบายหลักฐานเดิมภายในช่วงเดโม หยุดแก้ปัญหาหน้างานหลัง 10 วินาที ไม่ทดลองเปิดบริการใหม่ในเวลาพรี
