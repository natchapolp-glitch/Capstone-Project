1.1 ที่มาและความสำคัญ 
          ในยุคที่ปัญญาประดิษฐ์แบบประมวลผลเฉพาะถิ่น (Local/Edge AI) เข้ามามีบทบาทมากขึ้นใน
ชีวิตประจำวัน การนำแบบจำลองภาษาขนาดใหญ่ (Large Language Model, LLM) มาประมวลผล
โดยตรงบนอุปกรณ์ในที่พักอาศัย โดยไม่ต้องพึ่งพาการเชื่อมต่อคลาวด์ ได้กลายเป็นแนวทางที่ตอบโจทย์ทั้ง
ด้านความเป็นส่วนตัวของข้อมูล ความหน่วงในการตอบสนอง และต้นทุนการใช้งานระยะยาว โครงงาน
วิทยานิพนธ์ที่ผู้จัดทำดำเนินการมุ่งพัฒนาระบบประสาทส่วนกลางอัจฉริยะในที่พักอาศัยเพื่อสกัดและ
วิเคราะห์ข้อมูลห่วงโซ่อุปทานในครัวเรือน โดยอาศัยสถาปัตยกรรมที่เชื่อมโยงตั้งแต่กล้อง IP Camera 
ตรวจจับเอกสาร (YOLO) การสกัดข้อความด้วย OCR การประมวลผลด้วย Quantized Local LLM เพื่อ
สร้างโครงสร้างข้อมูล JSON และการเชื่อมต่อเข้ากับระบบบ้านอัจฉริยะ (Home Assistant ผ่าน MQTT) 
สำหรับพยากรณ์อัตราการสิ้นเปลืองสินค้าในครัวเรือน (burn rate) 
          จากการทบทวนวรรณกรรมเบื้องต้นที่เกี่ยวข้องกับการอนุมานแบบจำลองภาษาขนาดใหญ่บน
อุปกรณ์ประมวลผลเฉพาะถิ่น (on-device LLM inference) พบว่างานวิจัยที่ผ่านมามีแนวโน้มศึกษาปัจจัย
ด้านประสิทธิภาพแยกออกจากกันเป็นสามมิติหลัก ได้แก่ การบีบอัดแบบจำลองและสถาปัตยกรรม
ฮาร์ดแวร์ (quantization/hardware trade-off) การบังคับโครงสร้างผลลัพธ์ (grammar-constrained 
decoding/structured output) และการประยุกต์ใช้งานในบริบทบ้านอัจฉริยะ/IoT ปลายน้ำ โดยยังไม่มี
งานวิจัยฉบับใดประเมินปฏิสัมพันธ์ร่วมกันของทั้งสามมิตินี้ บนอุปกรณ์ single-board computer (SBC) ที่
มีทรัพยากรจำกัดจริงในบริบทที่พักอาศัย ช่องว่างดังกล่าวส่งผลให้ยังไม่มีแนวทางเชิงปฏิบัติที่ยืนยันได้ว่า
การบีบอัดแบบจำลองในระดับที่เหมาะสมกับ Edge Server ต้นทุนต่ำ จะยังคงให้ผลลัพธ์ JSON ที่มี
โครงสร้างถูกต้องเพียงพอสำหรับงานสกัดข้อมูลใบเสร็จและฉลากสินค้าในครัวเรือนหรือไม่ 
          Innovation ที่โครงงานนี้นำเสนอ คือการผสานทั้งสามมิติดังกล่าวเข้าด้วยกันในสถาปัตยกรรม
เดียวบนอุปกรณ์ระดับ SBC/Edge Server ต้นทุนต่ำ โดยใช้กล้อง IP Camera ตรวจจับเอกสารด้วย YOLO 
ร่วมกับ OCR สกัดข้อความ แล้วส่งต่อให้ Quantized Local LLM ที่ควบคุมด้วยเทคนิค Grammar-
Constrained Decoding ประมวลผลบนหน่วยประมวลผลเฉพาะทาง (NPU-centric) เพื่อแปลงข้อมูล
ใบเสร็จและฉลากสินค้าให้เป็นโครงสร้าง JSON ที่แม่นยำ ก่อนเชื่อมต่อเข้าสู่ระบบบ้านอัจฉริยะ (Home

สองชุดเข้าด้วยกัน สำหรับพยากรณ์ข้อมูลอนุกรมเวลาที่มีรูปแบบตามฤดูกาลจากข้อมูล IoT โดยไม่ระบุ
ฮาร์ดแวร์เฉพาะเนื่องจากเป็นแบบจำลองเชิงสถิติ เทคนิคนี้สามารถนำมาประยุกต์ใช้กับการพยากรณ์อัตรา
การสิ้นเปลืองสินค้าในครัวเรือน (burn rate) ได้ในเชิงหลักการ แม้จะไม่เกี่ยวข้องกับ LLM หรือความ
แม่นยำของการสกัดข้อมูลต้นทางก็ตาม

2.1.12 IoT Gateway น้ำหนักเบาบน ESP32 สำหรับบ้านอัจฉริยะ (Serepas et al., 2025) 
          คณะผู้วิจัยนำเสนอการออกแบบ IoT Gateway น้ำหนักเบาบนไมโครคอนโทรลเลอร์ ESP32 
(MCU-class) ที่รองรับโปรโตคอล MQTT และ REST API โดยมุ่งเน้นการใช้ทรัพยากร (resource 
footprint) ของ Gateway บน MCU ต้นทุนต่ำ ซึ่งสอดคล้องโดยตรงกับ Stage การเชื่อมต่อ Home 
Assistant ผ่าน MQTT ในสถาปัตยกรรมของโครงงานนี้ อย่างไรก็ตาม งานนี้ศึกษาเฉพาะชั้นเชื่อมต่อ 
(connectivity layer) เท่านั้น ไม่เกี่ยวข้องกับความแม่นยำของการสกัดข้อมูลจาก LLM ต้นทาง 
2.2 ทฤษฎีที่เกี่ยวข้อง 
           แนวคิดและทฤษฎีหลักในหัวข้อนี้สังเคราะห์ขึ้นจากงานวิจัยทั้ง 12 ฉบับที่ทบทวนในหัวข้อ 2.1 
เท่านั้น เพื่อให้ทฤษฎีพื้นฐานมีความสอดคล้องและตรวจสอบแหล่งที่มาได้ชัดเจน 
           แนวคิด Edge/Local AI คือการประมวลผลปัญญาประดิษฐ์ให้เกิดขึ้นใกล้แหล่งข้อมูลมากที่สุด
แทนที่จะส่งข้อมูลไปประมวลผลบนคลาวด์ ซึ่ง Cai et al. (2024) และ Husom et al. (2025) ต่างชี้ตรงกัน
ว่าแนวทางนี้ช่วยลดความหน่วง ลดต้นทุนแบนด์วิดท์ และรักษาความเป็นส่วนตัวของข้อมูลเมื่อเทียบกับการ
ประมวลผลบนคลาวด์แบบดั้งเดิม เทคนิคหลักที่ทำให้แบบจำลองภาษาขนาดใหญ่ทำงานได้บนอุปกรณ์
ทรัพยากรจำกัดคือ Model Quantization ซึ่งเป็นการลดความละเอียดของตัวเลข (precision) ที่ใช้แทน
พารามิเตอร์ของแบบจำลอง โดย Husom et al. (2025) แสดงให้เห็นเชิงประจักษ์ผ่านการประเมิน
แบบจำลอง Quantized LLM จำนวน 28 แบบจำลองว่าการลดระดับการบีบอัดข้อมูลมีความสัมพันธ์แบบ 
trade-off ระหว่างประสิทธิภาพเชิงพลังงานกับความแม่นยำของผลลัพธ์อย่างชัดเจน 
           ในด้านสถาปัตยกรรมฮาร์ดแวร์ NPU-centric Architecture คือการออกแบบให้หน่วยประมวลผล
เฉพาะทาง (Neural Processing Unit) เป็นแกนหลักในการอนุมานแบบจำลองภาษาเพื่อลดภาระของ
หน่วยประมวลผลกลางและหน่วยประมวลผลกราฟิก ดังที่ Yin et al. (2026) ออกแบบโมดูล Sparse 
Attention ที่คำนวณเฉพาะโทเคนสำคัญด้วย NPU บนสมาร์ตโฟน และ Moon et al. (2025) นำเสนอ
สถาปัตยกรรมผสมผสาน GPU-NPU (Hybe) สำหรับหน้าต่างบริบทขนาดล้านโทเคน อย่างไรก็ตาม Giedra 
et al. (2026) ยืนยันด้วยการวัดพลังงานจริงบนอุปกรณ์ NVIDIA Jetson Orin Nano Super (8GB) ว่า
ระดับการบีบอัดแบบจำลองขนาด sub-1B ถึง 8B พารามิเตอร์ส่งผลโดยตรงต่อทั้งความเร็วและความ
แม่นยำ ซึ่งเป็นข้อมูลเชิงปริมาณที่จำเป็นต่อการเลือกระดับ quantization ให้เหมาะกับ Edge Server ใน
ที่พักอาศัย

           ในชั้นการประยุกต์ใช้งานปลายน้ำ Time-Series Forecasting ด้วยแบบจำลอง Adaptive Holt-

สินค้าในครัวเรือน (burn rate) ได้ ส่วนการเชื่อมต่ออุปกรณ์ edge เข้ากับระบบบ้านอัจฉริยะนั้น Serepas 
et al. (2025) นำเสนอสถาปัตยกรรม IoT Gateway น้ำหนักเบาบนไมโครคอนโทรลเลอร์ ESP32 ที่รองรับ
โปรโตคอล MQTT และ Rivkin et al. (2025) แสดงให้เห็นว่าตัวแทน LLM อัตโนมัติสามารถเชื่อมต่อกับ
ระบบ IoT ในบ้านอัจฉริยะได้ ซึ่งทั้งสามงานนี้ยืนยันตรงกันว่าชั้นเชื่อมต่อปลายน้ำของสถาปัตยกรรมระบบ
ควรมีน้ำหนักเบาและไม่พึ่งพาทรัพยากรคำนวณส่วนกลาง

2.3.2 จุดที่เห็นตรงกัน (Consensus) 
          งานวิจัยทั้ง 12 ฉบับเห็นตรงกันในหลักการว่า การนำหน่วยประมวลผลเฉพาะทาง (NPU) หรือ
เทคนิคการบีบอัดแบบจำลอง (Quantization) มาใช้ร่วมกับการประมวลผลใกล้แหล่งข้อมูล (Edge/On-
device) เป็นแนวทางที่จำเป็นต่อการทำให้ระบบปัญญาประดิษฐ์ทำงานได้จริงภายใต้ทรัพยากรที่จำกัด โดย
งานวิจัยของ Husom et al. (2025) (ประเมินแบบจำลอง Quantized LLM ถึง 28 รุ่นบน Raspberry Pi 
4), Yin et al. (2026) และ Oloko-Oba et al. (2026) ต่างมุ่งลดการพึ่งพาคลาวด์ให้เหลือน้อยที่สุดหรือไม่
มีเลย เพื่อรักษาความเป็นส่วนตัวของข้อมูลผู้ใช้ ซึ่งสอดคล้องโดยตรงกับหลักการออกแบบสถาปัตยกรรม 
Local AI ของโครงงานนี้ ทิศทางเดียวกันนี้ยังปรากฏในงานสำรวจภาพรวมของ Zheng et al. (2025) ซึ่ง
ยืนยันว่าสายงานวิจัย edge LLM ทั้งสายกำลังมุ่งไปทาง on-device inference เป็นหลัก และสอดคล้อง
กับผลวัดเชิงประจักษ์ของ Giedra et al. (2026) ที่ยืนยันว่าการรันแบบจำลอง quantized บนอุปกรณ์ 
edge จริงอย่าง NVIDIA Jetson (ครอบคลุมโมเดล 12 แบบขนาด sub-1B ถึง 8B พารามิเตอร์) ให้ผลลัพธ์
ที่ใช้งานได้จริง หลักการเดียวกันยังปรากฏสม่ำเสมอในงานวิจัยชั้นปลายน้ำของสถาปัตยกรรม กล่าวคือ 
Rivkin et al. (2025), Sawalha and Al-Naymat (2025) และ Serepas et al. (2025) ต่างออกแบบให้
การเชื่อมต่อและประมวลผลข้อมูล IoT ในครัวเรือนเกิดขึ้นแบบเบา (lightweight) และไม่พึ่งพาทรัพยากร
คำนวณส่วนกลางเช่นเดียวกัน แม้แต่ในสายงานการบังคับโครงสร้างผลลัพธ์ Zheng et al. (2024) (เพิ่ม 
throughput ได้สูงสุด 6.4 เท่า) และ Hu et al. (2025) (ลดจำนวน visual token ได้มากกว่า 80%) ก็มี
เป้าหมายร่วมกันคือการลดภาระการประมวลผลของแบบจำลองภาษาโดยไม่ลดทอนคุณภาพผลลัพธ์ ซึ่งเป็น
หลักการเดียวกับที่พบในงานกลุ่ม quantization/hardware ข้างต้น

2.3.3 จุดที่ขัดแย้ง/ต่างกัน (Disagreement) 
          แม้จะเห็นพ้องในหลักการ แต่แต่ละงานวิจัยมีเป้าหมาย ระดับการพึ่งพาคลาวด์ และระดับฮาร์ดแวร์
ที่แตกต่างกันอย่างมีนัยสำคัญ กล่าวคือ Cai et al. (2024) ยังคงอาศัยการทำงานร่วมกันระหว่างอุปกรณ์ 
Edge และเซิร์ฟเวอร์คลาวด์บางส่วน (Hybrid) ในขณะที่ Husom et al. (2025), Yin et al. (2026) และ 
Oloko-Oba et al. (2026) เลือกประมวลผลภายในอุปกรณ์ทั้งหมด นอกจากนี้ Moon et al. (2025) มุ่ง
แก้ปัญหาหน้าต่างบริบทขนาดใหญ่ระดับล้านโทเคน ด้วยฮาร์ดแวร์ระดับเซิร์ฟเวอร์ (NVIDIA H100 ร่วมกับ 
NPU ที่ผลิตขึ้นเฉพาะด้วยเทคโนโลยี 4 นาโนเมตร) ซึ่งมีต้นทุนและขนาดสูงกว่าฮาร์ดแวร์ระดับ Raspberry 
Pi 4 (RAM 4GB) หรือสมาร์ตโฟนที่ใช้ในงานวิจัยอื่น ๆ อย่างมีนัยสำคัญ แสดงให้เห็นว่าผลการทดลองเรื่อง
ความเร็วและประสิทธิภาพพลังงานจากงานวิจัยที่ใช้ฮาร์ดแวร์ระดับสูงอาจไม่สามารถถ่ายโอนไปใช้กับ 
Edge Server ขนาดเล็กในบริบทที่พักอาศัยได้โดยตรง ความแตกต่างด้านระดับฮาร์ดแวร์นี้ปรากฏชัดยิ่งขึ้น
เมื่อพิจารณาสายงานการบังคับโครงสร้างผลลัพธ์ กล่าวคือ Zheng et al. (2024) ทดสอบเทคนิคเร่ง
ความเร็ว grammar-constrained decoding บนฮาร์ดแวร์ระดับ data center และ Hu et al. (2025) ใช้
แบบจำลองขนาดใหญ่ ยังไม่ได้ปรับให้ทำงานร่วมกับ quantized LLM บน SBC ในขณะที่ Giedra et al. 
(2026) วัดผล trade-off ระหว่างความแม่นยำและพลังงานบนอุปกรณ์ edge จริงโดยตรง (NVIDIA Jetson 
Orin Nano Super, 12 โมเดล) แสดงให้เห็นว่าแม้แต่ภายในสายงานเดียวกันก็ยังมีช่องว่างระหว่างงานที่
ทดสอบบนฮาร์ดแวร์สมรรถนะสูงกับงานที่ทดสอบบนฮาร์ดแวร์ทรัพยากรจำกัดจริง 
ในทำนองเดียวกัน 
งานวิจัยชั้นปลายน้ำอย่าง Rivkin et al. (2025), Sawalha and Al-Naymat (2025) และ Serepas et al. 
(2025) ก็มิได้กล่าวถึงข้อจำกัดด้านฮาร์ดแวร์ SBC หรือคุณภาพของผลลัพธ์เชิงโครงสร้างที่ส่งต่อมาจากชั้น
การประมวลผล LLM เลย — สะท้อนว่าแต่ละสายงาน ฮาร์ดแวร์/quantization, structured decoding, 
และการประยุกต์ใช้งานปลายน้ำ — ยังคงพัฒนาแยกกันโดยไม่มีงานใดเชื่อมโยงทั้งสามระดับเข้าด้วยกัน
ภายใต้เงื่อนไขฮาร์ดแวร์เดียวกัน 
 
 
2.3.4 ช่องว่างทางความรู้ (Research Gap) 
          งานวิจัยด้านการอนุมานแบบจำลองภาษาบนอุปกรณ์ประมวลผลเฉพาะถิ่น (on-device LLM 
inference) ในช่วงที่ผ่านมา มีแนวโน้มศึกษาปัจจัยด้านประสิทธิภาพแยกออกจากกันเป็นสามมิติหลัก 
แทนที่จะประเมินปฏิสัมพันธ์ร่วมกันภายใต้ทรัพยากรจำกัดจริงของอุปกรณ์ single-board computer 
(SBC) ในมิติแรก งานวิจัยกลุ่มที่มุ่งเน้นการบีบอัดแบบจำลอง (quantization) และสถาปัตยกรรมฮาร์ดแวร์

quantization ต่อความแม่นยำเชิง benchmark ทั่วไป มิได้เชื่อมโยงกับความแม่นยำของผลลัพธ์ที่มี
โครงสร้าง (structured output) ซึ่งเป็นรูปแบบผลลัพธ์ที่จำเป็นสำหรับงานสกัดข้อมูล ในมิติที่สอง งานวิจัย
ด้านการบังคับโครงสร้างผลลัพธ์ของแบบจำลองภาษาก็เป็นสายงานที่พัฒนาแยกต่างหากเช่นกัน ชี้ให้เห็นว่า
การบังคับ schema ระหว่างการถอดรหัสส่งผลโดยตรงต่อทั้งความเร็วและความถูกต้องของ JSON output 
แต่ยังไม่มีงานใดวัดผลกระทบนี้ร่วมกับระดับการบีบอัดแบบจำลองบนอุปกรณ์ edge NPU ทรัพยากรจำกัด
พร้อมกัน ในมิติที่สาม บริบทของการประยุกต์ใช้งานจริงในครัวเรือนก็เป็นสายงานที่พัฒนาคู่ขนานกันไป
เช่นกัน โดยศึกษาเฉพาะชั้นการเชื่อมต่อและการพยากรณ์ปลายน้ำ โดยไม่ได้เชื่อมโยงย้อนกลับไปถึงความ
แม่นยำของการสกัดข้อมูลต้นทางจาก LLM ภายใต้ข้อจำกัดด้าน quantization และ decoding ที่กล่าวถึง
